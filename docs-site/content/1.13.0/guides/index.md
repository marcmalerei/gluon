# Guides

These guides use the public `1.13.0` package entry points and the same
application contracts exercised by GLUON GOODS. Start with one path; use the
reference and recipes when you already know the task.

## Essentials

- [Getting started](getting-started/): install, author, check, and build a
  browser application.
- [Learn Gluon step by step](learning-path/): a progressive path through
  templates, reactivity, lists, styles, cleanup, and tests.
- [Build one stateful component](first-component/): follow requirement → state
  → event → render → lifecycle → cleanup → parent usage.

## Build an application

- [Components: properties, events, and lifecycle](components/): choose an
  authoring model and build typed component boundaries.
- [Choose a component level](component-decisions/): decide between native
  markup, Quark, Atom, Molecule, Organism, Custom Element, and app-local code.
- [Application architecture](application/): connect application ownership,
  Router, Store, and cleanup.
- [Async component data and SSR](async-ssr/): choose browser-only, blocking,
  progressive, prefetch, or component-owned async work.
- [Presentational Single-File Components](sfc-authoring/): enable `.gluon`,
  author typed markup and styles, and understand its supported boundary.

## Render and ship

- [Universal rendering](universal-rendering/): SSR, hydration, streaming, and
  SSG boundaries.
- [Tooling workflow](tooling/): Vite, diagnostics, Devtools, testing, and
  Playground.
- [Quality and security](quality/): accessibility, CSP, dependency, and
  browser gates.
- [Deployment](deployment/): static and server output from the reference shop.
- [Release readiness](releasing/): lockstep evidence, protected publication,
  and external prerequisites.

## Choose another entry point

- [Package reference](/gluon/1.13.0/packages/): compare runtime boundaries and
  ownership before installing.
- [Cookbook](/gluon/1.13.0/cookbook/): see several public packages working
  together in one task.
- [API reference](/gluon/1.13.0/api/): look up an exact export or symbol.
