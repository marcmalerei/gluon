# Support matrix

The versioned documentation publishes the current Gluon compatibility boundary
for the `1.8.1` package line: Node runtimes, Chromium/Firefox/WebKit lanes,
native stylesheet prerequisites, SSR, accessibility evidence, responsive
testing, and package-specific non-goals.

Read the [full support matrix in the repository](https://github.com/marcmalerei/gluon/blob/main/docs/support-matrix.md)
and the [detailed accessibility evidence](https://github.com/marcmalerei/gluon/blob/main/docs/accessibility.md)
before making a branded-browser, assistive-technology, or editor-distribution
claim.
