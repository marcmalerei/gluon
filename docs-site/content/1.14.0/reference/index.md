# Reference

Use the reference when you know the boundary or contract you need. Start with
the package portal for ownership and runtime context, then open the generated
API or the focused operational contract.

## Choose a package

- [Package portal](../packages/): compare purpose, runtime, dependencies,
  installation, limits, and related guides.
- [Generated API](../api/): inspect every current public entry point and
  symbol with version-matched examples.

## Operational contracts

- [Support matrix](support-matrix/): current Node, browser, accessibility, and
  compatibility evidence.
- [Forms](forms/): request-free field state and native form ownership.
- [Hydration](hydration/): server/client handoff and recovery behavior.
- [Deployment](deployment/): static and server output boundaries.
- [Diagnostics](diagnostics/): compiler and migration diagnostic catalog.

## Documentation maintenance

The repository-level [documentation architecture](https://github.com/marcmalerei/gluon/blob/main/docs/documentation-architecture.md)
defines source ownership, versioning, stale-document classification, and the
README contract used by contributors.
